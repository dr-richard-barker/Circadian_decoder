# Contributing to Spaceflight Circadian Decoder

We welcome contributions to improve the analysis pipeline, dashboard, or documentation!

## How to contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/Circadian_decoder.git
   ```
3. **Create a branch** for your changes:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. **Make your changes** and commit them with descriptive commit messages.
5. **Push to GitHub** and **open a Pull Request** against the `main` branch.

## Code Style & Standards

- Keep python code clean and PEP8 compliant.
- Ensure any mathematical or statistical methodology is documented in comments.
- Test your changes before submitting.
- Document any changes to data inputs/outputs in `data/README.md`.

Thank you for helping improve space biology reproducibility!
